游戏工坊 · Agent Writes A Game

这次不是读页面，是写一个能玩的游戏。

在左边描述一个你想玩的小游戏，跑在浏览器里的 Agent 会直接生成一份完整、自包含的 HTML/CSS/JS， 放进右边的沙箱 iframe 里现场运行——不经过任何后端，代码全部在你自己的浏览器里生成和执行。 生成之后还能继续对话式地提要求，比如"加个计分板"或"难度调高一点"。

写一整个游戏比读页面难得多，需要一次性输出几百到上千 token 且格式不能错。这几个本地小模型大概率写不出能跑的完整游戏——这也是要测的地方。
Key 只存在你浏览器的 localStorage，请求直接从浏览器发到你填的地址，不经过 roam.xiaopingfeng.com。实测智谱的 Coding Plan（/api/coding/paas/v4）是思考模型，容易把 token 预算全烧在看不见的推理上、正式输出是空的——写游戏这种一次性大段输出的任务，建议用下面这个非思考的常规接口。
