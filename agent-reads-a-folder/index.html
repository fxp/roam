文件柜 · Agent Reads A Folder

这次给它一把钥匙，只开一个抽屉。

用浏览器原生的 File System Access API 选一个文件夹——Agent 能看到的， 就是你选的这一个文件夹里的文件，仅此而已。它不能自己去点"选择文件夹"， 这一步必须是你在系统弹窗里亲手点的；它也只能读，不能改、不能删、不能新建文件。

权限边界，说清楚： 只读、不写；只看你选的这一个文件夹（不含子文件夹）； 权限只在这个标签页存在期间有效，关掉标签页或刷新页面就要重新选一次； 没有任何内容会被发到 roam.xiaopingfeng.com 或任何服务器——如果你选了云端 API 作为推理来源， 文件内容会被发给你自己配置的那个 API 地址（这是模型推理本身需要的，跟本地读取是两回事）。
